# Security Policy

## Reporting Security Vulnerabilities

If you discover a security vulnerability in this project, please report it responsibly by using the GitHub Security Advisory form instead of creating a public issue.

**Report here:** https://github.com/hsaito/VE_Count_Consolidator/security/advisories/new

Please include:
- A description of the vulnerability
- Steps to reproduce (if applicable)
- The potential impact
- Any suggested fixes (if you have them)

## Security Scanning

This project is regularly scanned for vulnerabilities using [Snyk](https://snyk.io/). We continuously monitor dependencies and code for known security issues.

## Support Level

This is a community project maintained on a best-effort basis. While we strive to address security issues promptly, there are no guaranteed response times. We appreciate your patience and understanding.

Thank you for helping keep this project secure!
